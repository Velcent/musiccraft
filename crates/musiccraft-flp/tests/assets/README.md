# PyFLP test assets

These files are copied unchanged from PyFLP's `tests/assets`
(https://github.com/demberto/PyFLP, commit `f937126`), Copyright (C) 2022
demberto, licensed GPL-3.0-or-later (see the repository's `LICENSE`).
They were made by PyFLP's contributors in FL Studio for PyFLP's tests.

`tests/pyflp_golden.rs` reads each with `musiccraft-flp` and compares the
result with what PyFLP read from it (`tests/golden`, regenerated by
`difftest/run.sh`).
